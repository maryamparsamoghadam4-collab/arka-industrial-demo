# ARKA — Industrial Corporate Website

A premium, modern corporate website template designed for industrial and B2B companies.

## Live Demo

[View Live Demo](https://maryamparsamogh...github.io/arka-industrial-demo/)

## About

ARKA is a reusable industrial website template focused on strong visual presentation, modern UI, responsive design, and clear business communication.

## Features

- Premium industrial-focused design
- Fully responsive layout
- Cinematic hero section
- Product showcase
- Product listing and pagination
- Search functionality
- FAQ section
- Trusted By section
- Contact hub
- Smooth animations and interactions
- Reusable HTML, CSS and JavaScript structure
